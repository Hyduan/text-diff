# 比一比 · TextDiff

两段文本，一眼看清不同。

比一比是一款计划面向 Windows 和 macOS 的轻量桌面文本对比工具，支持离线使用，文本在本地处理。

## 计划功能

- 左右文本编辑与对比，突出新增、删除和修改内容。
- 中文逐字对比，以及按行对比。
- 打开或拖入文本文件。
- 同步滚动，跳转到上一处或下一处差异。
- 忽略空白、忽略大小写等对比选项。

## 技术选型

- 桌面框架：Tauri 2
- 界面：React + TypeScript
- 前端构建：Vite
- 文本编辑：CodeMirror 6
- 差异计算：jsdiff（`diff`）
- 本地能力：Rust + Tauri 插件
- 前端包管理：pnpm
